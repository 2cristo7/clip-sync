# Installing ClipSync

## macOS (Apple Silicon)

1. Download `ClipSync.dmg` from the [latest release](https://github.com/2cristo7/clip-sync/releases)
2. Open the DMG and drag ClipSync to your Applications folder
3. On first launch, macOS may ask you to approve it in **System Settings → Privacy & Security**

Requires macOS 14 (Sonoma) or later.

## Windows

1. Download `ClipSync.msi` from the [latest release](https://github.com/2cristo7/clip-sync/releases)
2. Run the installer and follow the prompts
3. ClipSync appears in your Start menu

Requires Windows 10 or later.

## Linux

### AppImage (any distro)

1. Download `ClipSync.AppImage`
2. Make it executable: `chmod +x ClipSync.AppImage`
3. Run it: `./ClipSync.AppImage`

### Debian/Ubuntu (.deb)

```bash
sudo dpkg -i clipsync_0.1.0_amd64.deb
```

Requires Ubuntu 22.04+ or equivalent (libwebkit2gtk-4.1, libgtk-3).
